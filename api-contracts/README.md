# API Contracts

**Status:** Active  
**Owner:** Backend Lead + Mobile Lead

The contract surface between mobile and backend. **No undocumented endpoint may be called from production mobile builds.**

## Versioning

All endpoints under `/v1/`. Breaking changes require a new prefix (`/v2/`) and a deprecation window of at least one full release cycle.

## Files

| File | Purpose |
|---|---|
| [auth.md](./auth.md) | OTP request, verify, exchange, refresh, logout |
| [shifts.md](./shifts.md) | List shifts, get shift detail |
| [sync.md](./sync.md) | Submit envelope, query status |
| [media.md](./media.md) | Presigned upload, finalize |
| [error-codes.md](./error-codes.md) | Canonical error catalogue |
| [openapi.yaml](./openapi.yaml) | Machine-readable spec (OpenAPI 3.1); markdown is authoritative until S1, after which the YAML is generated from FastAPI and diffed in CI |

## Common conventions

### Base URLs

| Env | URL |
|---|---|
| dev | `https://api.dev.fieldwork.example.com` |
| staging | `https://api.staging.fieldwork.example.com` |
| pilot | `https://api.pilot.fieldwork.example.com` |
| prod | `https://api.fieldwork.example.com` |

### Headers (required on all authenticated calls)

| Header | Value |
|---|---|
| `Authorization` | `Bearer <internal_jwt>` |
| `X-Request-ID` | UUID v4 generated by client per request |
| `X-Device-ID` | Stable UUID from `flutter_secure_storage` |
| `X-App-Version` | Semantic version, e.g. `1.0.0+42` |
| `X-Platform` | `ios` or `android` |
| `Idempotency-Key` | UUID, required on POST `/sync/envelope`, `/media/finalize` |

### Response envelope

Success:
```json
{ "data": { ... } }
```

Error:
```json
{
  "error": {
    "code": "VALIDATION_FAILED",
    "message": "Human-readable summary",
    "request_id": "8f...",
    "details": [ { "field": "phone", "issue": "INVALID_FORMAT" } ]
  }
}
```

### Status codes

| Code | Use |
|---|---|
| 200 | Successful read |
| 201 | Resource created |
| 202 | Accepted, processing async |
| 204 | No content |
| 400 | Validation error |
| 401 | Auth required / token expired |
| 403 | Forbidden / not mapped |
| 404 | Not found |
| 409 | Conflict (duplicate client_id with different payload) |
| 422 | Semantic validation (e.g. wrong shift state) |
| 429 | Rate limit |
| 500 | Server error |
| 503 | Upstream (Odoo) unavailable |

### Auth boundary

| Endpoint | Auth |
|---|---|
| `/healthz`, `/readyz` | none |
| `/v1/auth/exchange`, `/v1/auth/refresh` | bounded (Supabase JWT or refresh token) |
| Everything else | internal JWT |

### Request validation

- All bodies validated by Pydantic strict.
- Unknown fields are rejected (`extra = "forbid"`).
- Numeric fields use bounded types where possible.
- Strings have max lengths.

### Force update

On any authenticated response, header `X-Min-App-Version: 1.0.0` may be set. Mobile compares; if local app is below the threshold, it shows a blocking update screen.

### Rate limits

| Endpoint | Default | Bucket |
|---|---|---|
| `/v1/auth/*` | 10 / min / device | per-device |
| `/v1/sync/envelope` | 60 / min / employee | per-employee |
| `/v1/media/presign` | 60 / min / employee | per-employee |
| `/v1/shifts` | 30 / min / employee | per-employee |

Exceeded → `429` with `Retry-After`.

### CORS

Mobile uses native HTTP, not browser; CORS is permissive but origin-checked for staging Web admin (post-MVP).

### TLS

TLS 1.2+ enforced. HSTS on all envs.
